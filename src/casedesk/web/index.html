HOW CASEDESK WORKS

Agent 提建议，你来做决定。

  1. 检索上下文

    读取工单、订单和知识库，保留可以核对的证据。

  2. 执行确定性规则

    退款等操作先通过代码定义的政策校验，模型草稿不等于授权。

  3. 生成处理建议

    把证据、规则结论和客户回复草稿放在一起供人工检查。

  4. 人工审批并留痕

    审批需要匹配工单版本，重复请求通过幂等键保护。演示操作只写入本地记录。

这是演示工作台，不连接真实消息或支付渠道。
